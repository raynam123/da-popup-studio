# 画面风格 · 水粉彩铅纸艺（watercolor-papercraft）

> 已用于《星星上的小旅人》《小红帽》。每个物件都像从一本精美绘本上剪下来的纸片：手绘插画 + 真实纸张。

## 1. 美术规范

| 方面 | 规范 |
|---|---|
| 画材 | 手绘水粉 + 彩铅，细腻纸纹，轻微丝网印刷颗粒 |
| 线条 | 干净、轮廓清晰；不要粗黑描边，不要商业动画感 |
| 视角 | 正面平视、扁平 2D；立体感由纸雕分层和光影产生，不靠画里的透视 |
| 配色 | 每本书定 5–6 色主调，柔和雅致；**暖金 + 奶白**是全系列共同色 |
| 角色 | 头稍大的儿童绘本比例，表情清楚，姿势一眼读得出在做什么 |
| 反派 | 滑稽不吓人：不露尖牙、不流血，笑点大于压迫感 |
| 不要 | 照片写实、赛博霓虹、高饱和报纸色、画里自带文字/边框、投影和地面（程序加） |

已用配色（新书另定一组，写进提示词文档开头）：
- 《星星上的小旅人》：午夜蓝、暖金、珊瑚红、薄荷绿、奶白 —— 夜空与星光
- 《小红帽》：深森林绿、番茄红、暖金、薄荷绿、奶白、木棕 —— 童话村庄与森林

配色选法：从故事的主场景和时间（夜/昼/室内）出发，定 1 个主色 + 1 个强调色 + 暖金奶白 + 1–2 个辅助色。

## 2. 提示词拼法

每条 = **画面描述** +（画面里有谁就加谁的**角色设定**）+ **通用风格后缀**（放最后）。

### 通用风格后缀（只替换括号里的配色）

```text
立体书纸艺插画风格，手绘水粉加彩铅质感，带细腻的纸张纹理和轻微的丝网印刷颗粒；配色以（本书的 5–6 种主色）为主，柔和雅致；线条干净，轮廓清晰；正面平视，扁平2D，主体完整居中，四周留出充足空白；透明背景PNG，无投影，无地面，无文字，无边框，不要裁切。
```

### 角色设定写法

年龄和体型 → 脸和发型 → 标志性服饰（颜色 + 材质 + **一个让人认得出的小细节**）→ 随身道具 → 性格关键词。
例：小红帽的「斗篷边缘绣一圈奶白小雏菊」。一段 60–120 字，整段原样复用，不要每条改写。

### 画面描述写法

- 一句话说清**是什么 + 在做什么 + 朝向**（「身体朝右」「侧身朝左」——程序按朝向让角色滑动、面对彼此；左边角色朝右，右边角色朝左）。
- 场景物件写清**构图比例和底边**（「横向构图，底部是平直的草地切边」），这样放到纸雕层上底边能落地。
- 两种状态的图（花苞/盛开、衣柜关/开、篮子空/满）：第二张写「与上一张同样大小和轮廓」，并让用户拿第一张当参考图。
- 旋转件（风车叶片、齿轮、转盘花）：写「正圆形，圆心在画面正中央」。
- 室内墙、天空大背景这类整幅远景，可以写「铺满画面」，并说明不要透明背景（这类图例外）。

## 3. 素材清单规则（给用户的生图任务）

1. 一张图一个物件；透明背景 PNG；长边 ≥ 1024 px；四周留白。
2. **先做角色参考图**（`00_` 开头，2:3 全身正面），之后每张有该角色的图都把参考图一起传进去，保证同一张脸。
3. 命名 `页号_名称.png`：`00_小红帽_参考.png`、`C1_封面.png`、`S3_篮子_满.png`。
4. 分 **★ 必需** 和 **☆ 加分**：必需的做完就能搭出完整的书；加分的增加细节和互动，缺了用代码画的占位或直接省略。
5. 天空、草地条、书页底纹、纸张切边、白色纸芯、星星、光效由程序绘制，**不用生成**。
6. 生图工具的半透明光晕、比例偏差不用用户修：`tools/prep_assets.py` 统一去光晕、裁紧、压缩。
7. 全部打包成一个 zip；只做好一部分也可以先发。

一本 5 个跨页的书大约 25–40 张（必需 20–30）。每个跨页的典型配置：
- 远景层 1–3 张（远景树林、挂饰、窗户、太阳等，天空程序画）
- 中景层 1–3 张（主建筑/大物件，比如小屋、橡树、床）
- 前景层 3–6 张（角色、道具、可点的小动物）
- 主机关需要的状态图 / 动作图 1–3 张
- 封面 1 张（1:1 圆形小插画构图）+ 桌面小道具 0–1 张

## 4. 提示词文档的结构（交付给用户的 MD）

按 `templates/prompts_template.md`：开头说明画风和配色 → 使用说明（上面 7 条）→ 通用风格后缀 → 角色设定 → 分镜总览表（页 / 画面 / 页面文字 / 互动机关）→ 逐张提示词（文件名 · 比例 · ★☆ · 要加的角色设定 · 在书里的用途 + 代码块描述）→ 交付清单表。

## 5. 版权与内容

- 角色外形不要向知名作品靠拢（反例：小星太像小王子，公开发布前必须按设定重画那 6 张）。
- 改编只用原创或已进入公有领域的故事（格林、安徒生、伊索、中国民间故事等），并写明是改编。
- 可怕情节改温和版：狼不吃人、外婆躲进衣柜、坏人被吓跑而不是被杀。
