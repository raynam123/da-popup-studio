# 视频风格 · 立体书（popup-book）

> 一句话：**放在暖黄台灯下木桌上的一本手工纸艺立体书**——剪纸人物站在层层纸雕里，翻开会弹起来，拉一拉、转一转、点一点都会动，发光的地方真的发光。
> 实现：`engine/`（Three.js r128 纸雕引擎）+ 每本书一个 `story.js`。同一套产出：可玩的网页立体书 + 逐帧渲染的短片。

## 1. 书的结构

封面 + **5 个跨页**（引擎支持 3–8 页，5 页是系列标准）。每个跨页是三层 V 形折叠纸雕，翻开时一起站起来：

| 层 | 高度 | 放什么 | 例子 |
|---|---|---|---|
| 远景 back | 最高，顶部云朵波浪剪边 | 天空/墙面、太阳月亮、远山、挂饰 | 夜空、森林剪影、外婆卧室的墙 |
| 中景 mid | 中等 | 主场景建筑和大物件 | 小星球、小屋、大橡树、床、壁炉 |
| 前景 front | 最矮，底部草地/地板条 | 角色、小道具、可以点的东西 | 小红帽、妈妈、篮子、猫咪 |

纸质感：每个物件外圈白色纸芯切边 + 淡切口线；书页底色带纤维颗粒、烫金边框角花；台灯从左上方照下，纸雕投下真实影子。

构图规则：
1. 会动的物件完整地在中缝一侧，不跨中缝；不动的大场景可以跨（折痕就是立体书的味道）。
2. 左页底部留给正文纸签，右页底部留给纸舌头滑槽或转盘，纸雕不压住。
3. 角色面对面：左边的朝右，右边的朝左。
4. 每页留一个「藏东西」的地方放隐藏金星（找齐有流星雨）。

## 2. 互动机关库（引擎已实现）

每个跨页 **1 个主机关**推动故事（这一页「发生了什么变化」），再配 **3–6 个可点小互动**（每个有生命的东西一个小动作）。

| 机关 | 怎么玩 | 引擎 | 例子 |
|---|---|---|---|
| 拉纸舌头 | 拖/点右页前沿纸舌头，A→B | `sp.p`/`sp.pT` 0→1，`sp.onPull` | 点灯、纸鹤起飞、日落、出门、狼露馅 |
| 转盘 | 书页上的圆盘，绕着转，松手有惯性 | `makeDial` `dialStep` `sp.spin` | 齿轮转钟针、雏菊转盘开花 |
| 状态切换 | 同一物件换图，带弹跳 | 两张图 + `visible` 切换 + `startHop` | 花苞→盛开、衣柜关→开、篮子空→满 |
| 点击说话 | 点角色弹气泡 + 合成说话声，每次换一句 | `sp.taps: {m, say: [...], snd}` + `VOICES` | 所有角色 |
| 对话问答 | 一次点击一问一答，按顺序推进 | `say` + `after(sp, sec, fn)` | 「外婆，你的耳朵怎么这么大？」 |
| 遮挡登场 | 从树后、页边一点点露出/消失 | `clipX` / `clipPlane` | 狼从橡树后走出、从页边逃走 |
| 物件小动作 | 点一下做个动作，过会复位 | `sp.taps: {m, act}` | 松鼠钻树洞、猫伸懒腰 |
| 挂饰摇摆 | 从顶部线上挂下，点了会晃 | `hanger` `hangers` | 折纸星星、怀表、灯笼 |
| 隐藏星星 | 每页一颗金星 | `hiddenStar` | 全系列 |
| 自动演示 | 一键演完整本书，点画面接管 | story 的 `demoScript` | 全系列 |

## 3. 光效与动效

基调：夜里一盏暖黄台灯照着木桌。纸张保持自己的颜色，只有真正的光源发光（Bloom 阈值高，纸面不泛光）。

全书通用：泛光（太阳/灯/炉火/烛光/萤火虫/闪光粒子）· 暖色暗角 · 翻页时中缝飘金粉、展开的跨页上方少量闪烁光点 · 点到可点物进出小火花 · 拉完纸舌头一次光爆 + 微闪白 · 桌面氛围（冒热气茶杯、铅笔、折纸星星、丝带书签、光里灰尘、封面定时扫金光）。

用光讲故事：
| 情绪 | 做法 | 例子 |
|---|---|---|
| 温暖/完成 | 点亮窗户和灯，整体变暖变亮，撒彩纸 | 点灯、灯花盛开、团聚 |
| 悬念 | 台灯调暗到 7 成，镜头轻震，反派眼睛一闪 | 狼从树后走出 |
| 惊喜/突变 | 闪白 + 震动 + 一圈星芒 | 狼露馅 |
| 时间流逝 | 天色渐变，星星一颗颗亮起 | 沙丘日落 |
| 安静 | 光柱里飘灰尘，挂钟滴答 | 外婆卧室 |

**动作原则**（用户定的）：角色是平面纸片，以**平移、弹跳、缩放**为主，**不做大角度旋转**；只有本来就转的东西（风车、齿轮、转盘）和小幅摇摆（摇椅、挂饰、啄米的母鸡）可以转。每个有生命的东西要有持续的小动作：烟囱冒烟、树叶飘落、蝴蝶飞、小鸟跳。

## 4. 文字与界面

- 字体：书名/正文/气泡/字幕用站酷小薇（ZCOOL XiaoWei，「回」字已内置修复）；按钮/提示/页码用思源宋体。
- 正文：每页 **3 行，每行 ≤ 20 字**，左页底部奶白纸签，首字金色圆形（以引号开头不加）。句子短、口语、像读给孩子听，每页留一句有味道的对白。手机竖屏时正文另显示在书下方卡片。
- 气泡：奶白底、深紫细边、小尖角 + 硬阴影，弹出回弹；一句 ≤ 18 字。
- 界面：顶部深胡桃木标题栏（书名 + 星星数 + 自动演示 + 静音），底部翻页按钮 + 一句玩法提示（只说「拉什么、点什么」）。

## 5. 声音

全部程序合成（无版权、不占体积）：动作音（翻纸、弹起「啪」、纸舌头哒哒、转盘咔嗒、敲门、叮铃）· 说话声（每个角色一种音高音色的叽叽声；有配音的成片里自动静音）· 每页一种环境底噪（鸟鸣、林风、草地风、挂钟、炉火）。
**不配背景音乐**——网页和短片都只有音效；配乐只在用户明确要求时用 `mix.py --music`。

## 6. 短片规格

| 项目 | 规格 |
|---|---|
| 画幅 | 16:9，1920×1080，30 fps，H.264 CRF 19，AAC 192k |
| 时长 | 配音版由配音决定（5 页约 1.5–2.5 分钟）；无配音的预告短片 30 秒（story 自带 `filmShots/filmActs/filmSegs`） |
| 画面元素 | 隐藏所有按钮；左上角页码 + 章节名（每页开头 3 秒）；旁白=底部字幕；角色台词=对话气泡；要中英双语时在 cues.json 加 `en`（台词编号 → 英文），字幕和气泡下面多一行小号英文；结尾书名卡 4 秒 |
| 声音 | 音效版：只有音效；配音版：配音 + 音效（音效 -11 dB），整体 loudnorm -16 LUFS，无音乐 |
| 交付 | `_音效版.mp4` + `_配音版.mp4` + 两条音轨 stems + 封面（16:9 ×3、3:4 ×2） |

### 时间线（tools/plan.py 按配音自动排）
- 0.6 s 起封面旁白（S0）；之后每页：翻页 → 0.9 s 后镜头拉回全景 → 1.5 s 后第一句开口。
- 句间停顿：同一角色 0.35 s，换角色 0.55 s（台词里写了 `gap` 就用 `gap`）；每页结束留 1.3 s（最后一页 1.6 s）。
- 每页两个推近镜头：A 在本页 38 % 处，B 在 78 % 处，离开前回到全景；结尾书名卡前缓慢拉远。
- 每页动作顺序：角色说一句 → 主机关触发（cue 到具体台词上）→ 光效高潮 → 翻页。镜头一直在推、移、绕，没有完全静止的时刻。

### 渲染
- 确定性：Math.random 固定种子、模拟时钟逐帧推进，所以可以分段渲染、断点续渲，接缝无跳变。
- 软件 GL（swiftshader），1080p 带泛光约 **3–5 秒/帧**（2 核）：2 分钟成片约 3700 帧 ≈ 4–5 小时。先 6 帧预览，确认后再整段渲染。
