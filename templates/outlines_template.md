# 第 1 步 · 三个剧本大纲（写在回复里，不建文件）

三个方向要**真的不同**：不同的主角/视角、不同的情绪基调、不同的主机关玩法。不要三个只是换了名字的同一个故事。
常用的拉开方式：经典忠实改编 / 换主角视角重讲 / 原创新故事；或 温暖治愈 / 冒险悬念 / 搞笑反转。

每个大纲的格式：

```
### 方案 A ·《书名》—— 一句话卖点
- 主角：谁（年龄/物种 + 一个让人记住的特征）；配角 2–4 个
- 基调与配色：温暖/冒险/搞笑…；建议主色 5–6 个
- 封面：画面一句话
- 第 1 页 · 章节名：发生了什么 → 主机关（拉纸舌头/转盘/状态切换/遮挡登场…：A → B）
- 第 2 页 · …
- …（共 5 页，用户要求时 3–8 页）
- 结尾：最后一个画面 + 一句收束的话
- 为什么适合立体书：哪一页的机关最出彩、最适合做短视频封面
- 素材量估计：必需约 N 张 / 加分约 M 张；配音角色 K 个；成片约 X 分钟
```

最后一段：推荐哪个、为什么（一两句），并问用户选哪个或怎么混搭。

检查：
- 公有领域或原创；改编的经典写明出处。可怕情节换温和版。
- 每页的「变化」能被一个机关表现出来；文字说的事画面必须做得到（做不到就改文字）。
- 角色外形不向知名 IP 靠拢。
