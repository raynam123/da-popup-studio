# 第 2 步 · 详细剧情（故事文件）

交付成一份用户能直接修改的文档（环境支持在线文档就用在线文档，否则用 .md 文件），标题「《书名》立体书 · 故事文件」。确认后它是后面提示词、story.js、配音剧本的唯一依据。

## 文档结构

```
# 《书名》立体书 · 故事文件

- 结构：封面 + N 个跨页；改编自……（公有领域）/ 原创
- 画面风格：水粉彩铅纸艺（styles/visual/…）；视频风格：立体书（styles/video/…）
- 配色：A、B、C、D、暖金、奶白
- 角色：主角（一句外形 + 性格）、配角……（详细设定放到提示词文档）
- 隐藏物：每页一颗金星（或本书主题物：金心、橡果…），找齐有什么奖励

## 封面
- 画面：……
- 书名 / 副标题：……

## S1 · 章节名
- 剧情：两三句，发生了什么
- 三层纸雕：远景 …… / 中景 …… / 前景 ……
- 主机关：拉纸舌头（纸舌头文字：出发）—— A 状态 → B 状态
- 小互动（3–6 个）：点妈妈挥手说话；母鸡啄米；……
- 光效：用哪种情绪光（温暖/悬念/惊喜/时间流逝/安静）
- 页面正文（3 行，每行 ≤ 20 字）：
  1. ……
  2. ……
  3. ……
- 点角色时的台词（每个角色 2–3 句，≤ 18 字）：妈妈「……」「……」
- 隐藏星星：藏在哪里
- 玩法提示（一句，只说拉什么点什么）：……

## S2 …… （每页同样结构）

## 结尾
- 读完提示：……
- 结尾书名卡：书名 + 副标题
```

## 写法

- 每页一个「变化」= 主机关；变化发生的那一刻配一种光。
- 正文像读给孩子听：短句、口语、每页一句有味道的对白。
- 动作只用平移、弹跳、缩放、换图；不写需要角色大幅转身或复杂肢体动画的情节。
- 会动的东西不跨中缝；左页底部是正文纸签，右页底部是纸舌头/转盘。
- 同一个角色在多页出现时，尽量复用同一张图（省素材），需要不同姿势才另出图。
